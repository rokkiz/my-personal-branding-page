# My Learning: Page Structure and Routes

This document maps the **My Learning** dropdown to its Docusaurus pages. The
menu is implemented in `src/components/homepage/Header.jsx`; documentation
collections and route bases are configured in `docusaurus.config.js`.

## URL format

The site uses the Docusaurus base URL `/my-personal-branding-page/`.

- Local development: `http://localhost:3000/my-personal-branding-page/<route>`
- Published site: `https://rokkiz.github.io/my-personal-branding-page/<route>`

The route paths in the tables below are relative to the base URL. For example,
`/rn-core` resolves to
`https://rokkiz.github.io/my-personal-branding-page/rn-core`.

`Product Development` combines the Project Management collection with both
mobile documentation groups. `Personal Finance` currently shows the mobile SDK

## Nested documentation pages

Each collection uses the autogenerated sidebar from `sidebars-default.js`.
Nested page URLs are under the collection's route base in the tables above:

1. A page without a frontmatter `slug` uses its source path relative to the
   collection directory, with the `.md` or `.mdx` extension removed.
2. A page with frontmatter `slug` uses that slug under the collection's route
   base. Slugs such as `/` define the collection landing page.
3. The global `/my-personal-branding-page/` base URL is prefixed to the route
   when constructing a full site URL.

For example, `docs/android-core/chat/introduction.mdx` is routed under
`/android-core/chat/introduction`, while
`docs/android-core/quickstart.mdx` declares `slug: /` and is routed at
`/android-core/`.

## Route and content notes

- The Project Management labels are currently aliases for Dyte SDK and UI Kit
  documentation collections, not separate project-management content
  collections. The source directory and route base are the actual routing
  configuration.
- Docusaurus redirects provide legacy collection-root routes such as
  `/web-core`, `/react-web-core`, `/react-ui-kit`, `/angular-ui-kit`, and
  `/ui-kit` to their corresponding menu routes. `/web-core` remains a legacy
  URL; the collection ID is now `introduction-to-project-management`.
- The menu configuration is the source of truth for which destinations appear
  in the dropdown. The docs directories and autogenerated sidebar define the
  nested pages available after opening a collection.
